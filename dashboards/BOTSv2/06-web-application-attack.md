# Web Application Attack Dashboard

## Overview

The Web Application Attack Dashboard provides visibility into HTTP activity captured in the BOTSv2 dataset. The dashboard focuses on request patterns, HTTP errors, client request volume, HTTP methods, and suspicious user-agent behavior.

The dashboard uses Apache/web access logs with the `access_combined` sourcetype.

## Data Source

- Index: `botsv2`
- Sourcetype: `access_combined`
- Data Type: Web / HTTP Access Logs

---

## Panel 1 — Top Requested URIs & Status Codes by Client IP

### Purpose

Identifies the most frequently requested URI paths, associated client IP addresses, and HTTP status codes.

### SPL

spl
index=botsv2 sourcetype=access_combined
| stats count by clientip, uri_path, status
| sort - count
| head 10

Analysis

This panel helps identify high-volume URI requests and the HTTP responses generated by those requests. Repeated requests from the same client IP toward specific URI paths can provide useful context during web application investigation.

Panel 2 — HTTP Error Rate Analysis
Purpose

Analyzes HTTP responses with status codes of 400 or higher and displays their activity over time.

SPL
index=botsv2 sourcetype=access_combined status>=400
| timechart span=1h count by status
Analysis

This panel provides visibility into HTTP error activity over time. Concentrated or unusual increases in error responses can help identify potentially suspicious web activity or abnormal request patterns.

Panel 3 — Top Client IPs by Request Volume
Purpose

Identifies the client IP addresses generating the highest number of HTTP requests.

SPL
index=botsv2 sourcetype=access_combined
| stats count by clientip
| sort - count
| head 10
Analysis

High request volumes from individual client IPs can be investigated for possible automated activity, scanning, enumeration, or other abnormal web behavior.

Panel 4 — HTTP Methods Distribution
Purpose

Shows the distribution of HTTP methods and their corresponding HTTP status codes.

SPL
index=botsv2 sourcetype=access_combined
| stats count by method, status
| sort - count
Analysis

This panel provides visibility into HTTP methods being used and the resulting status codes. It can help analysts understand the web application's request patterns and identify unusual method/status combinations.

Panel 5 — Top User-Agents (Bot/Scanner Detection)
Purpose

Identifies the most frequently observed user-agent strings in HTTP requests.

SPL
index=botsv2 sourcetype=access_combined
| stats count by useragent
| sort - count
| head 10
Analysis

User-agent analysis can help identify automated clients, bots, scanners, or other non-standard web clients. Frequently occurring user-agents can be investigated alongside source IP and request activity.

Panel 6 — Non-Browser/Suspicious User-Agents
Purpose

Identifies user-agents that do not contain the Mozilla string and associates them with client IP addresses.

SPL
index=botsv2 sourcetype=access_combined
| stats count by useragent, clientip
| where NOT match(useragent, "Mozilla")
| sort - count
| head 20
Analysis

This panel helps isolate requests using user-agent strings that do not match the common Mozilla pattern. Such traffic can be investigated further for automated tools, scanners, scripts, or other non-browser clients.

Investigation Value

The dashboard supports web application security monitoring by combining:

URI request analysis
HTTP error monitoring
Client IP request-volume analysis
HTTP method analysis
User-agent analysis
Non-browser client identification

These views can be used together during investigation to identify unusual web request behavior and prioritize potentially suspicious client activity.
