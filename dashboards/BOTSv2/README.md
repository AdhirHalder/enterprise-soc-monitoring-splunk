# BOTSv2 Dashboards

This folder contains dashboards developed using the Splunk Boss of the SOC (BOTSv2) dataset for security monitoring, threat hunting, and investigation.

## Dashboards

### 01. Palo Alto Firewall Dashboard
Analyzes Palo Alto firewall activity to identify network traffic patterns, suspicious connections, and security events.

### 02. MySQL / Database Attack Dashboard
Provides visibility into MySQL and database-related security activity, including suspicious connections and authentication behavior.

### 03. Symantec Endpoint Protection Dashboard
Analyzes endpoint security telemetry from Symantec Endpoint Protection to identify suspicious endpoint activity.

### 04. O365 Activity Dashboard
Monitors Microsoft Office 365 activity and administrative events for potentially suspicious account or configuration changes.

### 05. Lateral Movement Dashboard
Investigates network and authentication activity associated with potential lateral movement across systems.

### 06. Web Application Attack Dashboard
Analyzes web application telemetry to identify suspicious requests, reconnaissance, and potential attack activity.

## Dataset

- BOTSv2
- Splunk Enterprise
- Palo Alto Firewall
- MySQL
- Symantec Endpoint Protection
- Microsoft O365
- Web Application Telemetry

## Investigation Focus

The dashboards support investigation of:

- Firewall activity
- Database attacks
- Endpoint security events
- O365 administrative activity
- Lateral movement
- Web application attacks
- Suspicious network connections
